# SRO HUB DEVELOPMENT - GitHub Pages

## تشغيل الموقع على GitHub Pages

1. ادخل إلى GitHub وسجل الدخول.
2. اضغط **New repository**.
3. سمّي المستودع مثلا: `sro-hub`
4. اجعله **Public**.
5. اضغط **Create repository**.
6. ارفع كل محتويات هذا المجلد، خصوصا:
   - `index.html`
   - مجلد `assets`
7. افتح **Settings → Pages**.
8. تحت **Build and deployment** اختر:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
9. اضغط **Save**.
10. بعد دقائق سيظهر رابط الموقع.

## ملاحظة
الموقع Static بالكامل، لذلك لا يحتاج PHP أو MySQL أو VPS.
